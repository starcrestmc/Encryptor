friend, and they should rename it to your name. so you have a copy with their
name and they have a copy with your name

then your friend should generate their master file (these master files need to be
different) and you should both think of a number 1-1000 for each other (don't
share this with each other) then you both need to choose option 3 and first choose
the F option and use that number you each memorised when it asks for the password number. (your numbers should be different and the other person doesn't need to know this number)

note down this number in real life and keep it safe on a piece of paper or
something physical. 

now finally you can choose the password for the master vault same for your friend (next time you want
to encrypt a friends vault you will need to use this password first to unlock the

now both of you should have all your files encrypted, you will use these numbers in encryption and decryption so keep them available on hand

Glossary

HTML:
Hyper Text Markup Language - This is the code that is used to make websites and can be viewed in any text editor to see the code

PGP:
Pretty Good Privacy - this is a method of encryption using your keypair (public.asc & private.asc) to encrypt and decrypt files. It uses your private key to encrypt files and your public key to decrypt files

JSON:
JavaScript Object Notation - This is a file format, in simple terms its a list that assigns meaning to values in a readable format

PKL:
Pickle - This is a file format that stores words, in a way that is fast to access with python using the "pickle" module

SHA 256 Hash: This is a lots of characters that are a representation of a file using maths, this is unique.

Encryption: The process of taking a piece of information and making it unreadable without a password or key

File: A thing with an extension (examples: .txt, .py, .html, .pkl, .json) which stores data

Folder: A named container which stores files in one place

Python: You silly billy, python is the entire program that makes this all possible :)
